# MythicArsenal v2.2.0 (50 3D Animated Custom Items for Paper 1.21.11)

## IMPORTANT: How to get the real `.jar` file (DO NOT rename the folder to `.jar`!)
Renaming a source folder to `.jar` causes:
`Directory 'plugins/.paper-remapped/MythicArsenal.jar' does not contain a paper-plugin.yml or plugin.yml!`

### Easy 1-Click Build on GitHub (No Java/Maven needed on PC):
1. Create a free repository on GitHub.
2. Upload the contents of the `MythicArsenal/` folder (`pom.xml`, `src/`, and `.github/`).
3. Go to the **Actions** tab on GitHub -> click **Build MythicArsenal JAR** -> click **Run workflow**.
4. Download the compiled `MythicArsenal-2.2.0.jar` from Artifacts and put THAT `.jar` into `plugins/`.

## Resource Pack
Upload `MythicArsenal_ResourcePack_v4.zip` directly to `https://mc-packs.net/` and put the link in `server.properties`.
